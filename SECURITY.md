# Security Policy

## Supported version

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** feature under the repository's Security tab. Do not include credentials, tokens, account identifiers, or other private information in a public issue.

Include the affected version, macOS version, reproduction steps, and expected impact. Maintainers should acknowledge a report within seven days.

## Scope

Security-sensitive areas include child-process handling, JSON-RPC parsing, preference storage, release packaging, and accidental credential disclosure.
